# Contributing

Thanks for contributing to Human Hacking Lab.

## Requirements

Contributions must remain within the project's safety model:

- synthetic identities and data only;
- isolated/local infrastructure;
- no real credential collection;
- no targeting of third parties;
- no instructions whose primary purpose is compromising systems outside an authorized lab.

## Pull requests

Include:

1. What changed.
2. Why it is useful for training.
3. How it was tested.
4. Security/safety considerations.

Keep exercises reproducible and document the expected evidence.

## Development principle

Prefer defensive validation, observable telemetry and reversible lab actions over destructive exploitation.
