# Security Policy

## Scope

This project is an educational cybersecurity laboratory. The repository itself should never contain:

- passwords or API keys;
- personal data;
- real phishing credentials;
- production configuration;
- private infrastructure details.

## Reporting a repository vulnerability

If you discover a security issue in the repository or its build process, please report it privately through GitHub's security reporting mechanism when available. Do not publish sensitive details in a public issue.

## Safe-use requirement

Only use the laboratory against assets you own or are explicitly authorized to test. The exercises are intended for isolated, synthetic environments.
